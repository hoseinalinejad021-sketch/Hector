# هیکتور — دستیار شخصی اندروید

## وضعیت نسخهٔ توسعه
نسخهٔ فعلی شامل ورود با زیست‌سنجی پشتیبانی‌شدهٔ گوشی، گفت‌وگوی متنی، حافظهٔ محلی رمزگذاری‌شده، ورودی گفتار فارسی از سرویس تشخیص گفتار نصب‌شده روی گوشی، و خواندن پاسخ با موتور تبدیل متن به گفتار گوشی است.

## اتصال هوش مصنوعی
هیکتور مدل هوش مصنوعی را داخل APK حمل نمی‌کند. برای دریافت پاسخ واقعی باید در «تنظیم اتصال هوش مصنوعی» نشانی HTTPS سازگار با OpenAI Chat Completions، نام مدل و کلید API معتبر وارد شود. کلید API در فضای خصوصی برنامه با Android Keystore و AES-GCM رمزگذاری می‌شود؛ هیچ کلیدی در مخزن یا APK جاسازی نشده است. بدون این تنظیمات، پیام ذخیره می‌شود اما پاسخ مدل دریافت نمی‌شود.

## امنیت و محدودیت‌ها
- HIC-STOP-01 توقف نرم‌افزاری داخل برنامه است: نشست را قفل می‌کند، درخواست جاری را لغو می‌کند و برای ادامه احراز هویت مجدد می‌خواهد. این کلید فیزیکی مستقل در برابر حذف برنامه یا دست‌کاری سیستم نیست.
- زیست‌سنجی اندروید از روش پشتیبانی‌شدهٔ دستگاه استفاده می‌کند. برنامه نمی‌تواند تضمین کند که روش دوم حتماً تشخیص چهره باشد یا چهرهٔ پیمان را به‌صورت مستقل تطبیق دهد؛ تشخیص چهرهٔ اختصاصی هنوز پیاده‌سازی نشده است.
- گفتار برای مکالمه با احراز هویت صوتی یکی نیست. ورودی مکالمه با سرویس گفتار گوشی فعال می‌شود؛ برنامه عمداً فایل‌های صوتی نامرتبط را نمی‌خواند.
- کد آزمایشی SpeakerModelEngine و VoiceIdentityFlow احراز هویت قابل اتکا نیستند؛ مدل ONNX مورد انتظار در دارایی‌های برنامه موجود نیست و تشخیص زنده‌بودن/ضدبازپخش تأیید نشده است. این کدها نباید عملیات حساس را باز کنند.
- حافظهٔ محلی با AES-GCM و کلید Android Keystore رمزگذاری می‌شود. پشتیبان‌گیری اندروید و ترافیک HTTP بدون رمزگذاری غیرفعال‌اند.
- موفقیت CI فقط ساخت APK و بررسی امضای آن را تأیید می‌کند؛ نصب و آزمون روی گوشی فیزیکی هنوز باید جداگانه انجام شود.

## ساخت
گردش‌کار GitHub Actions از Java 17، Android SDK و Gradle 8.9 استفاده می‌کند و APK آزمایشی را به‌صورت artifact با نام Hector-debug-APK منتشر می‌کند. نسخهٔ فعلی برای arm64-v8a ساخته می‌شود تا حجم APK کمتر شود؛ روی دستگاه‌های فقط ۳۲ بیتی نصب نخواهد شد.
