# هیکتور — دستیار شخصی اندروید

## وضعیت نسخهٔ توسعه
نسخهٔ توسعه شامل ورود مرحله‌ای با زیست‌سنجی اندروید، بررسی حرکت زندهٔ چهره با دوربین جلو و چالش گفتاری تصادفی فارسی، گفت‌وگوی متنی، حافظهٔ محلی رمزگذاری‌شده و گفتار فارسی است. چالش‌های چهره/گفتار هنوز احراز هویت بیومتریک مستقل یا ضدجعل تأییدشده نیستند.

## اتصال هوش مصنوعی
هیکتور مدل هوش مصنوعی را داخل APK حمل نمی‌کند. برای دریافت پاسخ واقعی باید در «تنظیم اتصال هوش مصنوعی» نشانی HTTPS سازگار با OpenAI Chat Completions، نام مدل و کلید API معتبر وارد شود. کلید API در فضای خصوصی برنامه با Android Keystore و AES-GCM رمزگذاری می‌شود؛ هیچ کلیدی در مخزن یا APK جاسازی نشده است. بدون این تنظیمات، پیام ذخیره می‌شود اما پاسخ مدل دریافت نمی‌شود.

## امنیت و محدودیت‌ها
- HIC-STOP-01 توقف نرم‌افزاری داخل برنامه است: نشست را قفل می‌کند، درخواست جاری را لغو می‌کند و برای ادامه احراز هویت مجدد می‌خواهد. این کلید فیزیکی مستقل در برابر حذف برنامه یا دست‌کاری سیستم نیست.
- ورود پایه سه مرحله دارد: زیست‌سنجی دستگاه، تشخیص حضور و حرکت سر با دوربین جلو، سپس گفتن عبارت تصادفی. اندروید حسگر زیست‌سنجی را انتخاب می‌کند؛ برنامه نمی‌تواند آن را فقط به اثر انگشت یا فقط چهره محدود کند. دوربین چهره را با قالب مالک ذخیره‌شده تطبیق نمی‌دهد.
- چالش گفتاری تصادفی، تطبیق صدای مالک یا ضدبازپخش معتبر نیست؛ سرویس تشخیص گفتار نصب‌شده روی گوشی متن را برمی‌گرداند و ممکن است طبق تنظیمات خود به شبکه متکی باشد. مدل معتبر تطبیق چهره و ضدجعل صوت هنوز لازم است. برنامه به فایل‌های صوتی نامرتبط دسترسی نمی‌گیرد.
- کد آزمایشی تشخیص هویت گوینده در مسیر legacy/voice_identity_prototype/ نگه‌داری شده و در APK فعال کامپایل نمی‌شود؛ مدل ONNX و آزمون‌های ضدبازپخش/زنده‌بودن برای آن آماده نیستند. این کد نباید عملیات حساس را باز کند.
- حافظهٔ محلی و کلید API با AES-GCM و کلید Android Keystore رمزگذاری می‌شوند. پشتیبان‌گیری اندروید و ترافیک HTTP بدون رمزگذاری غیرفعال‌اند.
- موفقیت CI فقط ساخت APK و بررسی امضای آن را تأیید می‌کند؛ نصب و آزمون روی گوشی فیزیکی باید جداگانه انجام شود.

## ساخت
GitHub Actions از Java 17، Android SDK و Gradle 8.9 استفاده می‌کند و APK آزمایشی را با نام Hector-debug-APK منتشر می‌کند. نسخهٔ فعال از CameraX و ML Kit برای بررسی حرکت چهره و تشخیص گفتار سیستم برای چالش تصادفی استفاده می‌کند؛ این موارد جایگزین مدل تطبیق هویت چهره/گوینده نیستند.
