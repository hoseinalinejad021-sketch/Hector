# هیکتور — دستیار شخصی اندروید

## وضعیت منبع فعلی
- شناسهٔ برنامه: `com.hector.android`
- نسخهٔ ثبت‌شده در Gradle: `1.6.0-background-voice`، کد نسخهٔ 26
- حداقل Android API: 23؛ `compileSdk` و `targetSdk`: 36
- این شاخه منبع کد است؛ تا زمانی که نتیجهٔ CI، امضای APK و آزمون دستگاه بررسی نشده، نباید آن را نسخهٔ آمادهٔ انتشار دانست.

**این نسخه ورود زیست‌سنجی، اثر انگشت، تشخیص چهره، دوربین یا تشخیص هویت صوتی ندارد.** برنامه مستقیم به صفحهٔ اصلی می‌رود. فایل‌های راهنمای قدیمی مربوط به این قابلیت‌ها تاریخی‌اند و دستورالعمل معتبر برای نسخهٔ فعلی نیستند.

## اتصال هوش مصنوعی
برای دریافت پاسخ متنی، در «تنظیم اتصال هوش مصنوعی» یک نشانی HTTPS سازگار، نام مدل و کلید API معتبر وارد کن. برنامه درخواست متنی را مستقیماً به نشانی تنظیم‌شده می‌فرستد؛ پس فقط ارائه‌دهنده‌ای را انتخاب کن که به آن اعتماد داری. حافظهٔ محلی و تاریخچهٔ گفت‌وگو ممکن است همراه درخواست ارسال شوند. کلید API نباید در مخزن یا داخل APK ثابت شود.

قابلیت GPT-Live از سرویس صوتی پیش‌زمینه و WebSocket استفاده می‌کند. برای آن به مجوز میکروفون، دسترسی شبکه و حسابی با دسترسی API لازم نیاز است. اشتراک ChatGPT به‌تنهایی تضمین‌کنندهٔ اعتبار API یا دسترسی به مدل صوتی نیست.

## حافظه و Firebase
- یادداشت و تاریخچهٔ محلی با AES-GCM و کلید Android Keystore ذخیره می‌شوند.
- همگام‌سازی ابری اختیاری است و به فایل Firebase درست برای `com.hector.android`، ورود Email/Password، پایگاه Firestore و قوانین منتشرشده نیاز دارد.
- فقط حافظه و تاریخچه برای همگام‌سازی در نظر گرفته شده‌اند؛ کلید API، نشانی سرویس و مدل نباید همگام شوند.
- توکن FCM به‌صورت خصوصی به حساب واردشده پیوند می‌خورد؛ ارسال اعلان واقعی به یک سرور مورداعتماد یا Cloud Function نیاز دارد.

## امنیت و محدودیت‌ها
- `HIC-STOP-01` توقف نرم‌افزاری داخل برنامه است، نه کلید فیزیکی یا قفل امنیتی اندروید. وقتی فعال است، درخواست‌های هوش مصنوعی و نشست صوتی باید متوقف بمانند تا کاربر آن را دستی لغو کند.
- برنامه از `FLAG_SECURE`، `allowBackup=false` و `usesCleartextTraffic=false` استفاده می‌کند.
- محیط کدنویسی، فایل‌ها را فقط در فضای کاری خصوصی نگه می‌دارد و کد ذخیره‌شده را اجرا نمی‌کند.
- پوشهٔ `legacy/voice_identity_prototype/` فقط نمونهٔ قدیمی است و در APK فعال وارد نمی‌شود.
- موفقیت ساخت یا بررسی ایستای کد به‌تنهایی عملکرد روی گوشی، دسترسی API، همگام‌سازی Firebase، تحویل اعلان یا معتبر بودن امضای انتشار را ثابت نمی‌کند.

## ساخت و انتشار
گردش‌کارهای GitHub Actions در این مخزن تنظیم شده‌اند، اما نتیجه باید از اجرای واقعی همان commit تأیید شود. APK آزمایشی با APK امضاشدهٔ انتشار یکسان نیست. پیش از نصب یا توزیع، شناسهٔ بسته، شمارهٔ نسخه، گواهی امضا و SHA-256 را بررسی کن و آزمون‌های لازم را روی دستگاه واقعی انجام بده.
