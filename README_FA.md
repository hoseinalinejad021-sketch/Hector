# هیکتور — پروژهٔ اولیهٔ تأیید هویت و اجازهٔ کاربر

## هدف این نسخه
اولویت فعلی فقط این است که کاربر هویت خود را از طریق قابلیت زیست‌سنجی/قفل دستگاه تأیید کند و سپس خودش دکمهٔ «تأیید من برای ادامهٔ ساخت» را بزند. قابلیت‌های بعدی تا زمان بررسی و تأیید کاربر اضافه نمی‌شوند.

## محتویات
- `MainActivity.kt`: صفحهٔ نمونه برای تأیید هویت و ثبت اجازهٔ ادامه.
- `security/EmergencyStop.kt`: شناسهٔ توقف اضطراری `HIC-STOP-01`.
- فایل‌های Gradle و Manifest برای پروژهٔ پایهٔ Android Studio.

## محدودیت‌های مهم
- این یک پروژهٔ اولیه است، نه APK نهایی و نه پروژه‌ای که ساخت آن در این محیط با Android SDK آزمایش شده باشد.
- زیست‌سنجی سیستم‌عامل فقط تأیید می‌کند که فرد مجازِ دستگاه احراز هویت شده؛ هویت پیمان را به‌صورت مستقل یا از طریق تشخیص صدای واقعی اثبات نمی‌کند.
- دکمهٔ تأیید در این نمونه فقط پیام وضعیت را تغییر می‌دهد؛ هنوز فرایند ساخت/نصب خودکار یا قفل مجوزهای واقعی به آن متصل نشده است.
- توقف اضطراری فعلی فقط متغیر درون‌حافظه‌ای است و با راه‌اندازی مجدد پایدار نمی‌ماند. پیش از استفادهٔ واقعی باید توقف پایدار، آزمون‌شده و مستقل از عامل طراحی شود.

## ساخت در Android Studio
پروژه را در Android Studio باز کنید و اجازه دهید Gradle همگام‌سازی شود. برای ساخت APK از مسیر Build > Build APK(s) استفاده کنید. نسخه‌های Android Gradle Plugin و SDK ممکن است به نصب یا به‌روزرسانی ابزارهای Android نیاز داشته باشند.

## گام بعدی
پیش از افزودن صدا، حافظه یا قابلیت‌های دیگر، ابتدا پروژهٔ کامل فعلی و نتیجهٔ ساخت را بررسی کنید؛ سپس طراحی تأیید هویت و مجوزها را آزمایش کنید.
