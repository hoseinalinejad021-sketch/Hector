# Changelog

All notable Hector Android changes are recorded here.

## 1.5.1-stop-only (versionCode 25)

- Added the Code Studio entry point and AI-assisted code generation/editing.
- Hardened API requests with HTTPS validation, redirect rejection, timeouts and emergency-stop checks.
- Improved GPT-Live startup timeout and audio buffering/error handling.
- Added a CI emulator test suite for encrypted local storage and primary home-screen actions.
- Added Persian privacy-policy draft and Play Store metadata checklist.

### Release status
This entry does not itself certify a public production release. The current CI may produce a diagnostic debug APK when release-signing secrets are not configured. A production release requires a verified, stable release signing key, successful device tests, a public privacy-policy URL, and completed store disclosures.
