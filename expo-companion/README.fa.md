# پیگیری درخواست‌های شغلی هیکتور (Expo)

این پروژه یک برنامهٔ جداگانه است و فایل‌های برنامهٔ اصلی اندرویدی هیکتور را تغییر نمی‌دهد.

## امکانات فعلی
- ثبت نام شرکت، عنوان شغل، پیوند آگهی، مهلت، اقدام بعدی و یادداشت
- نمایش سوابق
- ویرایش، حذف و تغییر وضعیت درخواست
- ذخیرهٔ محلی روی دستگاه

## حریم خصوصی
نسخهٔ اولیه از AsyncStorage استفاده می‌کند؛ این ذخیره‌سازی به‌تنهایی رمزگذاری اختصاصی محسوب نمی‌شود. اطلاعات حساس یا مدارک هویتی را وارد نکن. ورود کاربر، رمزگذاری پایگاه داده و همگام‌سازی ابری هنوز پیاده‌سازی نشده‌اند.

## ساخت APK
برای ساخت APK با EAS Build باید پروژه به حساب Expo متصل شود. پروفایل APK در فایل eas.json با نام preview تعریف شده است.

در محیط دارای Node.js:
1. وارد پوشهٔ expo-companion شو.
2. npm install
3. npx expo-doctor
4. npx eas-cli login
5. npx eas-cli build --platform android --profile preview

ساخت APK در این مخزن هنوز اجرا یا تأیید نشده است. این پوشه در شاخهٔ جداگانه قرار دارد و نباید بدون بررسی با برنامهٔ اصلی ادغام شود.
