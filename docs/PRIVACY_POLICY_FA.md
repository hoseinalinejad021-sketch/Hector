# سیاست حریم خصوصی هیکتور — پیش‌نویس انتشار

**وضعیت:** این سند پیش‌نویس قابل بازبینی است و تا زمان تکمیل موارد داخل کروشه، بررسی حقوقی متناسب با محل انتشار و انتشار در یک نشانی عمومی پایدار، برای ارسال به فروشگاه کافی نیست.

**آخرین بازبینی:** ۲۰ اکتبر ۲۰۲۶

## چه داده‌هایی در برنامه استفاده می‌شود؟

- **کلید API:** کاربر آن را وارد می‌کند. برنامه آن را با کلید ساخته‌شده در Android Keystore رمزگذاری می‌کند و متن رمز‌شده را در فضای خصوصی برنامه نگه می‌دارد. کلید API را در کد منبع یا فایل APK قرار ندهید.
- **حافظه و تاریخچهٔ گفت‌وگو:** یادداشت حافظه و تاریخچهٔ محلی به‌صورت رمز‌شده در فضای خصوصی برنامه ذخیره می‌شوند.
- **تنظیمات برنامه:** نشانی سرویس، نام مدل و وضعیت توقف اضطراری در تنظیمات خصوصی برنامه نگه‌داری می‌شوند؛ این موارد در حال حاضر به‌وسیلهٔ همان لایهٔ رمزگذاری حافظه رمز نمی‌شوند.
- **متن ارسالی به هوش مصنوعی:** پیام کاربر، تاریخچهٔ مربوط و یادداشت حافظه ممکن است برای تولید پاسخ به ارائه‌دهندهٔ API که کاربر پیکربندی کرده ارسال شود.
- **صدای زنده:** هنگام استفاده از GPT-Live، صدای میکروفون برای سرویس زندهٔ ارائه‌دهنده ارسال می‌شود و پاسخ صوتی از همان سرویس دریافت می‌شود.
- **تشخیص گفتار و تبدیل متن به گفتار سیستم:** قابلیت تشخیص گفتار اندروید و موتور TTS دستگاه ممکن است تابع شرایط و سیاست‌های ارائه‌دهندگان سیستم‌عامل یا موتورهای نصب‌شده باشند.

## با چه کسی داده به اشتراک گذاشته می‌شود؟

هیکتور سرور اختصاصی جمع‌آوری داده یا سامانهٔ تحلیل رفتار کاربر در این نسخه تعریف نکرده است. با این حال، وقتی قابلیت‌های آنلاین فعال باشند، محتوای لازم برای انجام درخواست به ارائه‌دهندهٔ API انتخاب‌شده ارسال می‌شود. برای نشانی پیش‌فرض OpenAI، سیاست‌های حفظ داده و شرایط سرویس OpenAI نیز اعمال می‌شوند. اگر کاربر نشانی ارائه‌دهندهٔ دیگری وارد کند، سیاست همان ارائه‌دهنده باید جداگانه بررسی شود.

## نگهداری و حذف داده

داده‌های رمز‌شدهٔ محلی در فضای خصوصی برنامه باقی می‌مانند تا کاربر آن‌ها را حذف کند یا برنامه را پاک کند. حذف برنامه معمولاً داده‌های خصوصی برنامه و کلید محلی Android Keystore را حذف می‌کند؛ رفتار نسخه‌های پشتیبان یا بازیابی دستگاه تابع تنظیمات و نسخهٔ اندروید است. هیکتور نسخهٔ پشتیبان Android را در مانیفست غیرفعال کرده است. مدت نگه‌داری داده‌هایی که به ارائه‌دهندهٔ API ارسال می‌شوند تابع سیاست آن ارائه‌دهنده و تنظیمات حساب کاربر است.

## امنیت

هیکتور از ارتباط HTTPS برای درخواست‌های API متنی و اتصال امن WebSocket برای صدای زنده استفاده می‌کند و ترافیک HTTP ناامن را در تنظیمات برنامه غیرفعال کرده است. هیچ برنامه‌ای نمی‌تواند امنیت کامل را تضمین کند. کاربر باید از اشتراک‌گذاری کلید API خودداری کند و در صورت افشا، آن را لغو کند.

## کودکان و اطلاعات حساس

هیکتور برای واردکردن اطلاعات حساس، مالی، پزشکی یا اطلاعات افراد دیگر بدون رضایت آن‌ها طراحی نشده است. پیش از انتشار عمومی، ردهٔ سنی و الزامات مربوط به کودکان باید با بازار هدف و قوانین محل انتشار تطبیق داده شود.

## پیش از انتشار الزامی است

1. موارد داخل کروشه را با اطلاعات واقعی ناشر جایگزین کنید.
2. متن را با رفتار نهایی برنامه، ارائه‌دهندگان واقعاً پشتیبانی‌شده و بازار هدف تطبیق دهید.
3. این سند را در URL عمومی و پایدار منتشر کنید و همان URL را در صفحهٔ فروشگاه ثبت کنید.
4. فرم Data safety فروشگاه را جداگانه و بر اساس رفتار واقعی برنامه و ارائه‌دهندگان تکمیل کنید.
5. تغییرات بعدی در ارسال داده، تبلیغات، تحلیل‌گرها یا SDKها را در سیاست و فرم فروشگاه منعکس کنید.
