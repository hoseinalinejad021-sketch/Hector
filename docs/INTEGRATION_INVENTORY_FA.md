# فهرست ادغام قابلیت‌های هیکتور — نسخهٔ ۱٫۴٫۰

این فایل مشخص می‌کند کدام قابلیت‌ها در سورس فعال برنامه قرار دارند، کدام موارد فقط نمونهٔ آزمایشی‌اند و چه چیزی هنوز تأیید نشده است.

## در سورس فعال برنامه و واردشونده در APK

1. **ورود زیست‌سنجی اندروید:** `MainActivity.kt` با `BiometricPrompt`. نوع حسگر را اندروید انتخاب می‌کند؛ برنامه نمی‌تواند روی تمام گوشی‌ها فقط اثر انگشت را تحمیل کند.
2. **مرحلهٔ دوربین:** `FaceLivenessChallengeController.kt` با CameraX و ML Kit، حضور یک چهره و حرکت سر را بررسی می‌کند. این مرحله تطبیق چهره با الگوی ذخیره‌شدهٔ مالک نیست.
3. **گفت‌وگوی فارسی صوتی:** ورودی گفتار با سرویس تشخیص گفتار نصب‌شده در گوشی؛ خروجی گفتار با Android TextToSpeech در صورت وجود دادهٔ صدای فارسی. این قابلیت گفت‌وگو است، نه احراز هویت با صدا.
4. **اتصال هوش مصنوعی:** نشانی HTTPS سازگار با OpenAI Chat Completions، نام مدل و کلید API توسط کاربر پیکربندی می‌شود. هیچ مدل یا کلید API در APK تعبیه نشده است.
5. **حافظهٔ محلی رمزگذاری‌شده:** یادداشت‌ها، تاریخچهٔ گفت‌وگو و کلید API با AES-GCM و کلید Android Keystore ذخیره می‌شوند.
6. **توقف اضطراری `HIC-STOP-01`:** نشست قفل می‌شود، درخواست شبکه قطع می‌شود و پاسخ‌های قدیمی نادیده گرفته می‌شوند. ذخیره یا برداشتن وضعیت توقف بررسی می‌شود؛ شکست ذخیره‌سازی نباید به بازشدن بی‌صدا منجر شود.
7. **دروازهٔ عملیات حساس:** `OwnerVerificationGate.kt` به‌صورت پیش‌فرض دسترسی را رد می‌کند. تا وقتی تطبیق مستقل هویت چهره/صدا و ضدجعل معتبر وجود نداشته باشد، نباید از آن برای مجازکردن عملیات حساس استفاده شود.

## عمداً وارد APK نشده

کدهای `SpeakerModelEngine.kt` و `VoiceIdentityFlow.kt` در `legacy/voice_identity_prototype/` نگهداری شده‌اند، اما در سورس فعال Android نیستند. فایل مدل ONNX موردنیاز وجود ندارد و تشخیص زنده‌بودن، مقاومت در برابر بازپخش و آستانهٔ تطبیق روی دستگاه واقعی اعتبارسنجی نشده‌اند. انتقال این نمونه به APK به‌عنوان ورود صوتیِ آماده، خطای امنیتی و عملکردی خواهد بود. جریان فعال فعلاً از زیست‌سنجی دستگاه و بررسی حرکتی دوربین استفاده می‌کند و صدای مکالمه فقط برای گفت‌وگو است.

## مواردی که CI نمی‌تواند تأیید کند

- نصب و بازشدن APK روی گوشی هدف؛
- رفتار واقعی حسگر زیست‌سنجی و دوربین گوشی؛
- ماندگاری حافظه پس از راه‌اندازی مجدد؛
- درستی کلید/نشانی API و پاسخ واقعی هوش مصنوعی؛
- دسترس‌پذیری صدای فارسی در TextToSpeech؛
- آزمون مستقل امنیت و مقاومت در برابر جعل.

موفقیت ساخت فقط پس از اجرای CI جدید گزارش می‌شود و به‌معنای تأیید موارد بالا نیست.
