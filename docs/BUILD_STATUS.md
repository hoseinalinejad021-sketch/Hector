# وضعیت ساخت هیکتور

## نسخهٔ ۱٫۴٫۰ — یکپارچه‌سازی پروژه
- شاخهٔ کاری: `integration/hector-1.4.0-android-2026-10-17`
- نسخهٔ برنامه: `1.4.0-integrated`، کد نسخهٔ ۱۴.
- قابلیت‌های فعال در یک پروژهٔ اندروید: ورود زیست‌سنجی دستگاه، بررسی حضور/حرکت چهره با دوربین، گفت‌وگوی فارسی صوتی، خروجی گفتار، حافظهٔ رمزگذاری‌شده، تنظیم اتصال HTTPS هوش مصنوعی و توقف `HIC-STOP-01`.
- اصلاح جدید: اگر ذخیرهٔ وضعیت توقف یا رفع توقف اضطراری شکست بخورد، برنامه نباید بی‌صدا از حالت توقف عبور کند.
- فهرست دقیق ادغام و محدودیت‌ها: `docs/INTEGRATION_INVENTORY_FA.md`.
- ساخت این شاخه باید پس از تغییرات دوباره در GitHub Actions اجرا شود؛ تا آن زمان نتیجهٔ ساخت نسخهٔ ۱٫۴٫۰ هنوز تأیید نشده است.

## مواردی که عمداً فعال نشده‌اند
- تطبیق اختصاصی چهره با الگوی ذخیره‌شدهٔ مالک.
- احراز هویت با صدای مالک و ضدبازپخش معتبر؛ نمونهٔ قدیمی به‌علت نبود مدل ONNX و آزمون‌های امنیتی در `legacy/voice_identity_prototype/` باقی می‌ماند و وارد APK نمی‌شود.
- عملیات حساس مالی یا کنترل دستگاه؛ دروازهٔ امنیتی برای شواهد ناقص دسترسی را رد می‌کند.

## آزمون‌های لازم پس از ساخت
1. اجرای آزمون‌های JVM و ساخت APK در CI.
2. بررسی امضای APK و وجود فایل خروجی.
3. نصب و اجرای واقعی روی گوشی هدف.
4. آزمون لغو/شکست ورود، توقف اضطراری و ماندگاری آن پس از راه‌اندازی مجدد.
5. آزمون قفل‌شدن در پس‌زمینه، قطع درخواست شبکه، حافظهٔ رمزگذاری‌شده، اتصال HTTPS و صدای فارسی.
