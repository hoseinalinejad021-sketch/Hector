# گزارش آزمون دستگاه واقعی هیکتور

**وضعیت فعلی:** در انتظار اجرای آزمون روی گوشی واقعی؛ این سند قالب ثبت شواهد است و **هیچ‌یک از آزمون‌های زیر را از پیش موفق اعلام نمی‌کند**.  
**آخرین به‌روزرسانی سند:** ۲۳ اکتبر ۲۰۲۶  
**برنامه:** `com.hector.android`  
**نسخهٔ موردنظر:** `1.6.0-background-voice` / `versionCode 26`

## ۱. مشخصات اجرای آزمون

| مورد | مقدار ثبت‌شده |
|---|---|
| مدل گوشی | هنوز ثبت نشده |
| نسخهٔ Android / سطح API | هنوز ثبت نشده |
| نوع نصب | انتخاب شود: نصب تازه / به‌روزرسانی |
| منبع APK | URL یا شناسهٔ artifact همان اجرای GitHub Actions را ثبت کنید |
| SHA-256 فایل APK | هنوز محاسبه/ثبت نشده |
| گواهی امضا / SHA-256 fingerprint | هنوز ثبت نشده |
| commit یا شناسهٔ اجرای CI | هنوز ثبت نشده |
| تاریخ و ساعت آزمون | هنوز ثبت نشده |
| آزمون‌گر | هنوز ثبت نشده |
| وضعیت نهایی | **NOT RUN — آزمون واقعی هنوز ثبت نشده است** |

**قاعدهٔ ثبت:** فقط پس از انجام هر مورد، نتیجه را «قبول» یا «رد» کنید. در صورت رد، پیام خطای دقیق، مراحل بازتولید و شواهد بدون اطلاعات محرمانه را ثبت کنید. موردی که اجرا نشده باید «اجرا نشده» باقی بماند.

## ۴. قواعد نتیجه‌گیری

- ساخت CI موفق به‌تنهایی اثبات نصب یا عملکرد روی گوشی واقعی نیست.
- تست روی شبیه‌ساز جایگزین تست روی مدل گوشی هدف نیست.
- آزمون‌های Firebase/FCM فقط با پیکربندی واقعی و رویداد موفق ثبت‌شده قابل تأییدند.
- آزمون امضا باید با APK همان اجرای CI، خروجی `apksigner verify`، گواهی مورد انتظار و SHA-256 همان فایل ثبت شود.
- موردی که به حساب، سرویس یا کلید محرمانه نیاز دارد و اجرا نشده است باید «اجرا نشده» بماند.
- **وضعیت نهایی تنها پس از ثبت شواهد و رفع موارد بحرانی/بالا قابل تغییر است.**
