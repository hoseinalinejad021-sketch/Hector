# نصب خصوصی هیکتور روی گوشی خودت (بدون Google Play)

این راهنما برای نصب شخصی روی گوشی اندرویدی است، نه انتشار عمومی در فروشگاه.

## چه چیزی از قبل در مخزن هست؟

- شناسهٔ بسته: `com.hector.android`
- `minSdk = 23` و `targetSdk = 36`
- مجوز اینترنت برای اتصال اختیاری به هوش مصنوعی و مجوز میکروفون برای قابلیت‌های صوتی
- پشتیبان‌گیری اندروید خاموش و ترافیک HTTP ناامن غیرفعال
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی، اجرای آزمون‌های JVM و بررسی امضای APK
- ساخت نسخهٔ انتشار امضاشده فقط در صورت تنظیم چهار راز امضای انتشار

## مسیر سادهٔ نصب شخصی

1. در مخزن خصوصی Hector، بخش **Actions** را باز کن و آخرین اجرای **Build Hector Android APK** را انتخاب کن.
2. مطمئن شو اجرای ساخت با وضعیت **Success** تمام شده باشد. اگر Failed است، APK را نصب نکن؛ ابتدا خطای همان اجرا باید رفع شود.
3. از بخش Artifacts، فایل `Hector-debug-diagnostic` را دریافت کن. این خروجی آزمایشی است و فقط برای نصب شخصی/عیب‌یابی است؛ نسخهٔ رسمی انتشار محسوب نمی‌شود.
4. فایل ZIP دانلودشده را در Files by Google باز و APK را استخراج کن.
5. اگر اندروید اجازه خواست، فقط برای برنامهٔ Files by Google اجازهٔ **Install unknown apps / نصب برنامه‌های ناشناس** را فعال کن. این تنظیم اجازهٔ نصب از همان منبع را می‌دهد؛ پس از نصب می‌توانی خاموشش کنی.
6. هشدارهای امنیتی را دور نزن. اگر Play Protect نصب را مسدود کرد، نام برنامه، منبع فایل و جزئیات هشدار را بررسی کن؛ صرفاً برای نصب، حفاظت را خاموش نکن.
7. پس از نصب، هیکتور را باز کن. برنامه باید مستقیم به صفحهٔ اصلی برود؛ هیچ ورود اثر انگشت، چهره، صدا یا رمز عبوری در طراحی فعلی وجود ندارد.
8. اگر نصب به‌عنوان به‌روزرسانی رد شد، ممکن است گواهی امضا با نسخهٔ قبلی متفاوت باشد. حذف نسخهٔ قبلی می‌تواند داده‌های محلی برنامه را پاک کند؛ پیش از حذف، این خطر را در نظر بگیر.

## اگر فایل دانلود نمی‌شود یا روی ۱٪ می‌ماند

- اول وضعیت اجرای GitHub Actions و آماده‌شدن Artifact را بررسی کن.
- اگر مخزن خصوصی است، باید با حسابی وارد شوی که دسترسی به مخزن دارد.
- فایل APK را از Artifact اجرای موفق بگیر؛ لینک Artifact موقت است و ممکن است پس از پایان مدت نگهداری حذف شود.
- برای تشخیص خطای نصب، متن دقیق پیام اندروید لازم است. فایل‌های مخزن نمی‌توانند مشکل اینترنت، فضای خالی گوشی، محدودیت دانلود یا هشدار Play Protect را از راه دور برطرف کنند.

## امضا و اعتماد

همهٔ APKها باید امضای دیجیتال داشته باشند. APK آزمایشی CI با کلید debug پایدار همان گردش‌کار امضا می‌شود. اگر می‌خواهی نسخهٔ انتشار خصوصی و به‌روزرسانی‌پذیر داشته باشی، باید کلید انتشار شخصی را امن نگه داری و رازهای لازم را در GitHub Actions Secrets تنظیم کنی. کلید خصوصی یا رمز آن را داخل مخزن نگذار.

## تأیید توسعه‌دهندهٔ اندروید

ثبت‌نام Google Play لازم نیست فقط برای اینکه فایل APK را شخصاً نصب کنی. قواعد Android developer verification در حال گسترش‌اند؛ طبق راهنمای رسمی فعلی، اجرای سراسری برای نصب از منابع متفرقه در سال ۲۰۲۷ برنامه‌ریزی شده و نصب با ADB برای توسعه و آزمایش از این الزام معاف است. اگر در آینده نصب مستقیم از Files روی دستگاه گواهی‌شده نیازمند ثبت توسعه‌دهنده شد، مسیر رسمی Android Developer Console و گزینهٔ مناسب استفادهٔ شخصی/محدود را دنبال کن. این تأییدیه با افزودن فایل یا مجوز به مخزن صادر نمی‌شود.

## مواردی که نیازمند دسترسی واقعی‌اند

مخزن نمی‌تواند به‌تنهایی اجازهٔ نصب ناشناس را در گوشی تو فعال کند، هشدار Play Protect را تأیید کند، هویت توسعه‌دهنده را به‌جای تو تأیید کند، یا تضمین کند فایل روی دستگاه مشخص نصب می‌شود. این موارد به تنظیمات گوشی، نتیجهٔ ساخت واقعی، کلید امضا و در صورت لزوم حساب رسمی توسعه‌دهنده وابسته‌اند.
