# اتصال هیکتور به Termux — راه‌اندازی و ایمنی

## این قابلیت چه کاری می‌کند؟

هیکتور ترموکس را داخل APK بسته‌بندی نمی‌کند. از دکمهٔ «اجرای فرمان در Termux» در Code Studio استفاده می‌کند تا فرمانی را که خودت وارد کرده‌ای و صریحاً تأیید کرده‌ای به برنامهٔ جداگانهٔ Termux بفرستد. خروجی در نشست Termux نمایش داده می‌شود؛ پیام هیکتور به‌تنهایی ثابت نمی‌کند فرمان با موفقیت تمام شده است.

## پیش‌نیازها

1. Termux باید روی گوشی نصب باشد. فقط از منبع رسمی Termux استفاده کن و نسخه‌های امضاشده از منابع متفاوت را روی هم نصب نکن.
2. در تنظیمات اندروید، به **Hector → Permissions / Additional permissions** برو و مجوز **Run commands in Termux environment** را به Hector بده.
3. در Termux، فایل `~/.termux/termux.properties` باید شامل این خط باشد:

```properties
allow-external-apps=true
```

برای تنظیم آن از خود Termux می‌توانی این فرمان را اجرا کنی:

```sh
mkdir -p ~/.termux
touch ~/.termux/termux.properties
sed -i '/^allow-external-apps=/d' ~/.termux/termux.properties
printf '\nallow-external-apps=true\n' >> ~/.termux/termux.properties
termux-reload-settings
```

این تنظیم به برنامه‌های دارای مجوز اجازه می‌دهد فرمان اجرا کنند؛ پس فقط به برنامه‌ای که به آن اعتماد داری این مجوز را بده.

## آزمایش اولیه

از Code Studio روی «اجرای فرمان در Termux» بزن، سپس فرمان سادهٔ `pwd` را وارد کن، متن را بررسی کن و «ارسال و اجرا» را انتخاب کن. Termux باید نشست فرمان را باز کند و مسیر پوشهٔ خانهٔ Termux را نشان دهد. سپس می‌توانی `ls -la` را امتحان کنی.

## محدودیت‌های امنیتی

- هیچ فرمانی صرفاً با تولید متن توسط هوش مصنوعی اجرا نمی‌شود؛ باید خودت دکمهٔ اجرا را بزنی و تأیید کنی.
- هیکتور فرمان‌های جدید را هنگام فعال بودن توقف اضطراری `HIC-STOP-01` ارسال نمی‌کند.
- توقف اضطراری، فرمانی را که قبلاً در Termux شروع شده متوقف نمی‌کند؛ در آن حالت باید در خود Termux از `Ctrl+C` استفاده کنی.
- فرمان‌های shell می‌توانند فایل‌ها را تغییر دهند، بسته نصب کنند یا به شبکه دسترسی داشته باشند. فرمان را پیش از تأیید بخوان و کلیدهای API، رمزها یا داده‌های محرمانه را در آن قرار نده.
- دسترسی فایل‌های هیکتور و Termux یکسان نیست. برای دسترسی به حافظهٔ اشتراکی اندروید، مجوزها و مسیرها باید جداگانه تنظیم شوند.
- این سند راهنمای تنظیم است؛ آزمون واقعی روی گوشی باید جداگانه انجام و ثبت شود.
