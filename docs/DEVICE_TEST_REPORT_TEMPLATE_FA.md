## نصب و به‌روزرسانی
- [ ] نصب تازه از APK امضاشده انجام شد.
- [ ] برنامه از صفحهٔ اصلی اجرا شد.
- [ ] نصب نسخهٔ جدید روی نسخهٔ قبلی با همان کلید امضا موفق شد.
- [ ] نصب با امضای متفاوت به‌درستی به‌عنوان به‌روزرسانی ناسازگار شناسایی شد (در محیط آزمایشی).

## داده و امنیت
- [ ] یادداشت محلی ذخیره شد و پس از بستن/بازکردن برنامه باقی ماند.
- [ ] تاریخچه پس از راه‌اندازی مجدد باقی ماند.
- [ ] توقف اضطراری درخواست متنی، تشخیص گفتار و صدای زنده را متوقف کرد.
- [ ] برنامه بدون اینترنت خطای قابل‌فهم نشان داد و از کار نیفتاد.
- [ ] کلید API و محتوای حساس در گزارش‌ها یا رابط کاربری ناخواسته ظاهر نشد.

## صدا
- [ ] مجوز میکروفون در اولین استفاده درخواست شد.
- [ ] رد مجوز باعث crash نشد.
- [ ] تشخیص گفتار فارسی آزموده شد (اگر سرویس دستگاه پشتیبانی می‌کند).
- [ ] خروجی TTS فارسی آزموده شد (اگر موتور دستگاه پشتیبانی می‌کند).
- [ ] GPT-Live صدای ورودی را دریافت و صدای خروجی پخش کرد.
- [ ] پایان تماس، قطع شبکه و مجوز لغوشده به‌درستی مدیریت شدند.
